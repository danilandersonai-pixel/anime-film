# anime-film · «Мишка»

Мультфильм, нарисованный кодом (HTML + canvas + JavaScript) по методичке
«Мультики кодом»: объёмная рисовка восковыми мелками и карандашом на бумаге,
со светом, тенями и бликами. 64 секунды, 16:9, 20 планов с разных ракурсов.

Сцена живёт в 3D: камера ходит по комнате, смотрит «глазами мишки», сверху,
снизу, через плечо, изнутри коробки. Люди нарисованы с настоящими пропорциями
возраста, лица и причёски честно поворачиваются в три четверти и профиль.

Плюшевый мишка семьдесят лет живёт в одной семье: в 1956 году его находит под ёлкой
пятилетняя Аня, потом он переходит к её дочке Лене, десять лет пылится в коробке на
чердаке, его находит внучка Катя, и в 2026 году прабабушка Аня сама отдаёт его
двухлетней правнучке Соне. Каждая девочка растёт у одного и того же дверного косяка с
карандашными отметками роста. На мишке остаются следы каждого поколения: синяя
пуговица вместо глаза, заплатка, вязаный шарф, заколка-сердечко.

Сценарий и раскадровка по секундам: [STORYBOARD.md](STORYBOARD.md).

## Как посмотреть

Проще всего запустить локальный сервер в папке проекта и открыть страницу:

```bash
npx serve .
# затем открыть http://localhost:3000
```

Можно открыть `index.html` двойным щелчком, но тогда браузер может не загрузить
локальный шрифт, и без интернета подписи будут запасным шрифтом.

Управление: кнопка «Смотреть со звуком», пробел — пауза, стрелки — перемотка по
секунде, по линейке-ростомеру можно прыгать к главам (1956, 1979, 2003, 2026).

## Как устроено

| Файл | Что внутри |
|---|---|
| `js/pencil.js` | движок: случайность с зерном, бумага, линия карандаша с нажимом и разрывами, штриховка, мелки, свет и объём, рукописный текст, палитры |
| `js/space.js` | 3D: камера с перспективой, проекция эллипсоидов и трубок, порядок рисования от дальнего к ближнему, тени на полу |
| `js/figures.js` | люди (скелет, обратная кинематика рук и ног, пропорции по возрасту, лица, причёски, платья) и мишка со следами поколений |
| `js/story.js` | раскадровка (объект `T` со временем каждого события), декорации четырёх эпох, чердак, коробка, 20 планов с камерами |
| `js/sound.js` | синтезатор: музыкальная шкатулка, шорох карандаша, тиканье лет, эффекты |
| `js/player.js` | плеер: воспроизведение, перемотка, палитры |
| `tools/frames.cjs` | снимает ключевые кадры и собирает лист кадров для проверки |
| `tools/render.cjs` | рендер в MP4 со звуком (Playwright + ffmpeg) |
| `tools/build-single.cjs` | сборка одного самодостаточного HTML-файла |
| `tools/lab.html`, `tools/lab.cjs` | «лаборатория»: персонажи с шести ракурсов для проверки |

Приёмы из методички, на которых держится «рисованный» вид:

- **На двойках.** Видео идёт 24 кадра в секунду, а рисунок меняется 12 раз в секунду.
- **Линии кипят.** Каждый рисунок перерисовывается чуть иначе. Случайность берётся только из
  генератора с зерном «ключ линии + номер рисунка», поэтому повторный рендер даёт тот же ролик.
- **Рваные линии и фактура.** Линия сужается на концах, местами прерывается, поверх
  идёт второй тонкий проход, замкнутый контур заходит за начальную точку. Бумага с
  зерном, волокнами, пятнами и следами ластика.
- **Объём мелками.** В каждой сцене есть источник света: окно, торшер, луна на чердаке.
  Каждая форма (голова, лапа мишки, платье, ёлочный шар, коробка) знает свою нормаль
  в 3D, и тон считается от света. Стены и пол темнеют с расстоянием от лампы или окна. На светлой стороне один слой
  мелка и блики белым мелком, в полутени второй слой, в тени холодный тёмный мелок и
  графитная штриховка, у края остаётся рефлекс. На полу лежат падающие тени. Воск не
  попадает в ямки бумаги, поэтому сквозь мелок просвечивает зерно.
- **Строительные линии.** Сначала голубым карандашом рисуются круги и оси, потом они гаснут.
- **Разные ракурсы.** Общий план, кран, «глазами мишки», через плечо, сверху, от пола,
  изнутри коробки. Камера «с рук» слегка покачивается, на кружении — наклон горизонта.
- **Цепочка сцен.** Рост у косяка заканчивается наездом на мишку, следующая эпоха
  начинается с него же.
- **Поворот на 43 % длины.** До открытия коробки на чердаке мир выцветший, как
  старая фотография. После — цвет. Тёплый акцент впервые появляется только в 2026 году.
- **Звук тоже код.** Время каждого звука берётся из тех же констант, что и картинка.

## Как перекрасить

Палитра задаётся одной строкой в начале `js/story.js`:

```js
const THEME = 'paper'; // 'paper' | 'notebook' | 'kraft'
```

Или кнопками «Бумага» под плеером. Сцены рисуются ролями цветов (`line`, `fur`, `a1`,
`a2`, `warm`…), поэтому весь фильм меняет цвет сразу.

## Как сделать MP4 и проверить кадры

Нужны Node.js 22, ffmpeg и Playwright с Chromium.

```bash
# лист ключевых кадров
NODE_PATH=$(npm root -g) node tools/frames.cjs out/frames "3.6,8.6,16.4,22,28.2,32.5,41.2,62"

# видео со звуком (≈5 минут на обычном ноутбуке)
NODE_PATH=$(npm root -g) node tools/render.cjs out/mishka.mp4
NODE_PATH=$(npm root -g) node tools/render.cjs out/mishka-kraft.mp4 kraft
```

Рендер сам выравнивает громкость до −15 LUFS с пиком не выше −1 dBFS.

Плеер подстраивает качество под устройство. Внутреннее разрешение выбирается по
размеру сцены на экране, а если кадр не успевает нарисоваться за 1/12 секунды,
штрихи мелка становятся шире и реже. Каждый кадр 3D-сцены рисуется заново, поэтому
на слабом телефоне рисунки могут пропускаться — для гладкого просмотра есть MP4.
MP4 всегда рендерится в полном качестве.
