# anime-film · «Мишка»

Карандашный мультфильм, написанный кодом (HTML + canvas + JavaScript), по методичке
«Мультики кодом». 58 секунд, 16:9.

Плюшевый мишка семьдесят лет живёт в одной семье: в 1956 году его находит под ёлкой
пятилетняя Аня, потом он переходит к её дочке Лене, десять лет пылится в коробке на
чердаке, его находит внучка Катя, и в 2026 году прабабушка Аня сама отдаёт его
правнучке Соне. Каждая девочка растёт у одного и того же дверного косяка с
карандашными отметками роста. На мишке остаются следы каждого поколения: синяя
пуговица вместо глаза, заплатка, вязаный шарф, заколка-сердечко.

Сценарий и раскадровка по секундам: [STORYBOARD.md](STORYBOARD.md).

## Как посмотреть

Проще всего запустить локальный сервер в папке проекта и открыть страницу:

```bash
npx serve .
# затем открыть http://localhost:3000
```

Можно открыть `index.html` двойным щелчком, но тогда браузер может не загрузить
локальный шрифт, и без интернета подписи будут запасным шрифтом.

Управление: кнопка «Смотреть со звуком», пробел — пауза, стрелки — перемотка по
секунде, по линейке-ростомеру можно прыгать к главам (1956, 1979, 2003, 2026).

## Как устроено

| Файл | Что внутри |
|---|---|
| `js/pencil.js` | движок карандаша: случайность с зерном, бумага, линия с нажимом и разрывами, штриховка, рукописный текст, камера, палитры |
| `js/story.js` | раскадровка (объект `T` со временем каждого события), мишка, люди, реквизит, шесть сцен |
| `js/sound.js` | синтезатор: музыкальная шкатулка, шорох карандаша, тиканье лет, эффекты |
| `js/player.js` | плеер: воспроизведение, перемотка, палитры |
| `tools/frames.cjs` | снимает ключевые кадры и собирает лист кадров для проверки |
| `tools/render.cjs` | рендер в MP4 со звуком (Playwright + ffmpeg) |
| `tools/build-single.cjs` | сборка одного самодостаточного HTML-файла |

Приёмы из методички, на которых держится «рисованный» вид:

- **На двойках.** Видео идёт 24 кадра в секунду, а рисунок меняется 12 раз в секунду.
- **Линии кипят.** Каждый рисунок перерисовывается чуть иначе. Случайность берётся только из
  генератора с зерном «ключ линии + номер рисунка», поэтому повторный рендер даёт тот же ролик.
- **Рваные линии и фактура.** Линия сужается на концах, местами прерывается, поверх
  идёт второй тонкий проход, замкнутый контур заходит за начальную точку. Вместо
  заливки — штриховка, бумага с зерном, волокнами, пятнами и следами ластика.
- **Строительные линии.** Сначала голубым карандашом рисуются круги и оси, потом они гаснут.
- **Цепочка сцен.** Каждая сцена заканчивается наездом на мишку, и следующая
  начинается с него же.
- **Поворот на 41 % длины.** До открытия коробки на чердаке мир выцветший, как
  старая фотография. После — цвет и крупные планы. Тёплый акцент впервые
  появляется только в 2026 году.
- **Звук тоже код.** Время каждого звука берётся из тех же констант, что и картинка.

## Как перекрасить

Палитра задаётся одной строкой в начале `js/story.js`:

```js
const THEME = 'paper'; // 'paper' | 'notebook' | 'kraft'
```

Или кнопками «Бумага» под плеером. Сцены рисуются ролями цветов (`line`, `fur`, `a1`,
`a2`, `warm`…), поэтому весь фильм меняет цвет сразу.

## Как сделать MP4 и проверить кадры

Нужны Node.js 22, ffmpeg и Playwright с Chromium.

```bash
# лист ключевых кадров
NODE_PATH=$(npm root -g) node tools/frames.cjs out/frames "0,7.9,16.7,24.1,40.6,57.9"

# видео со звуком (≈4 минуты на обычном ноутбуке)
NODE_PATH=$(npm root -g) node tools/render.cjs out/mishka.mp4
NODE_PATH=$(npm root -g) node tools/render.cjs out/mishka-kraft.mp4 kraft
```

Рендер сам выравнивает громкость до −15 LUFS с пиком не выше −1 dBFS.
