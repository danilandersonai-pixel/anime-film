# ORBITA Pulse One — рекламный ролик кроссовка кодом

Два рекламных ролика бегового кроссовка: «Улица» (26 с) — ночная улица под ливнем, кроссовок
падает в лужу по законам физики; «Анатомия» (30 с) — тёмная студия, кроссовок разбирается
на детали и шнуруется на глазах. Всё написано кодом — модель кроссовка, вода, камера,
режиссура, физика, звук. Один и тот же монтаж рисуется двумя способами:

- **кино** — трассировкой лучей в Blender Cycles (`cycles/render.py`): настоящие
  преломления в каплях, мягкие тени, глубина резкости объектива; кадр — около 40 секунд;
- **в реальном времени** — в браузере на [three.js](https://threejs.org) (`index.html`):
  тот же монтаж, свет и физика, можно остановить и покрутить кроссовок.

Скачаны только сканы, все свободные (CC0, [Poly Haven](https://polyhaven.com)):
панорама ночного Шанхая (огни города и отражения), асфальт и ткань канта.
ORBITA — вымышленная марка.

## Как посмотреть

```bash
cd sneaker
npx serve .
# открыть http://localhost:3000
```

Кнопка «Смотреть ролик со звуком» запускает рекламу. «Покрутить в 3D» включает
свободный осмотр: кроссовок можно вращать мышью или пальцем и менять расцветку
(Ember, Glacier, Volt). Пробел — пауза, ползунок — перемотка.

## Ролик v6 «Анатомия»: разбор, шнуровка, игра света

Тёмная студия: чёрный глянцевый пол, софтбокс, две контровые полосы, верхний прожектор
и узкая полоса света, которая бежит по поверхности. Фон — темнота.

| Время, с | План | Камера | Свет |
|---|---|---|---|
| 0–3 | Темнота, силуэт проявляется | низко, медленный наезд | полоса света идёт за кроссовком от пятки к носку и обводит силуэт |
| 3–7 | Макро вдоль всего кроссовка: задник, строчка, вязка, логотип, тросики, носок | скользит вдоль ткани в 5 см от поверхности, f/4 | полоса дважды проходит по ткани навстречу камере |
| 7–9 | Оборот на 360° и взлёт | отъезд от носка к общему плану | контровые, загорается прожектор |
| 9–14 | Разбор на 11 деталей с подписями | отходит и медленно облетает висящий «разрез» | пятно сверху, полоса проходит через разрез |
| 14–16 | Облёт со всех сторон | быстро вокруг: спина, внутренний бок, перед | |
| 16–17 | Карбоновая пластина между слоями пены | наезд сверху-сбоку, f/8 | блик бежит поперёк плетения |
| 17–19 | Сборка со щелчками, шнурки улетают, кроссовок садится на пол | отъезд и переход наверх | |
| 19–23,5 | Шнуровка: шнурок проходит крест-накрест через все 14 блочек и завязывается бантом | сверху-сбоку, едет за шнурком | полоса над подъёмом идёт следом |
| 24–27,5 | Оборот на 360° у пола | низко, медленный наезд | полоса проходит спереди |
| 27,5–30 | Три четверти, карточка | | |

**Детали** (`js/anatomy.js`): подмётка (две части), нижний и верхний слои пены, карбоновая
пластина, стелька, вязаный верх (с подкладкой, кантом, логотипом и строчкой), жёсткий задник
с петлёй, накладки и тросики, язык, блочки, шнурки. Каждая деталь — группа вокруг своего
центра; при разлёте её сдвиг и поворот умножаются на долю разлёта, которая идёт по пружине
(быстро и с перелётом ~10 %), детали стартуют по очереди снаружи внутрь. Сборка — снизу вверх
с ускорением к месту, как защёлка.

**Шнуровка**: шнурок в модели — ленты вдоль кривых; лента строится кольцами, поэтому её можно
«протягивать» — в плеере рисуется только первая доля колец, в Cycles прозрачна часть ленты
дальше доли (UV вдоль длины). Девять шагов по полдоли (120 уд/мин): перекладина внизу, шесть
пар отрезков крест-накрест, к узлу, бант и хвосты. Наконечники едут на переднем крае своего
конца шнурка — по цепочке отрезков, как настоящий конец, который продевают в блочки.

**Звук** (`js/audio6.js`): каждая деталь отщёлкивается своим материалом (резина, пена, карбон,
пластик, ткань, металл блочек), при сборке — каскад защёлок, шнурок «вжикает» через блочки
и тикает металлом, бегущий свет звучит стеклянным мерцанием; музыка с двумя «дропами» —
на разборе и на финальном обороте.

## Физика падения

Кроссовок — твёрдое тело в плоскости: масса, момент инерции, центр масс ближе к пятке
(там толще пена и задник). Подошва касается асфальта 25 точками по изогнутому контуру
подмётки. Пена в каждой точке — пружина с демпфером (сжатие — миллиметры), трение
мокрой резины ограничено μ = 0,65. Шаг интегрирования 1/24000 с. Падение примерно с 30 см:
удар пятки 2,4 м/с, через 13 мс хлопок передом, качание на носок (−24°) и обратно,
покой примерно через секунду. Из той же симуляции берутся сжатие пены, брызги
(баллистика 580 капель от двух ударов), кольца на воде и звук каждого касания.

## Оптика и цвет

| Что | Как сделано |
|---|---|
| Объектив | глубина резкости по тонкой линзе: кружок рассеяния r = K·|1/D − 1/d|; сцена в масштабе 1:10, поэтому диафрагма та же, что у настоящей камеры. В Cycles — камера с 7 лепестками, в three.js — `dof.js`: сбор «золотой спиралью» на половинном разрешении, боке-семиугольник |
| Фокус | в макро — автофокус лучом из центра кадра до ткани (как фокус-пуллер), дождь и брызги лучу не мешают |
| Капли | в Cycles — стекло n = 1,333; в three.js — `watermat.js`: шаровая линза, внутри перевёрнутый ночной город, блики фонаря и фар |
| Цвет | AgX (Blender «Medium High Contrast», three.js AgXToneMapping), экспозиция +0,3; лёгкая бочкообразная дисторсия и хроматизм, мягкое свечение огней |
| Плёнка | в итоговом видео — зерно по яркости и едва заметная виньетка (ffmpeg) |

## Как сделать фильм в Cycles

Нужны Node.js, ffmpeg, Playwright с Chromium и Blender как модуль Python (`pip install bpy`,
4.5 LTS). three.js берётся из `node_modules` (`npm install`), шрифты Google один раз
скачиваются в `tools/.fontcache`.

```bash
cd sneaker
npm install
# 1. сцена для Blender: GLB трёх кроссовков и состояние 625 кадров
NODE_PATH=$(npm root -g) node tools/export-cycles.cjs out/cycles
#    + оригинальная панорама shanghai_bund_2k.hdr → out/cycles/city.hdr
# 2. кадры: 1280×720, 12 сэмплов + шумодав OIDN, ~40 с на кадр на 4 ядрах (~6–7 часов)
setsid nohup bash cycles/render-all.sh > render.log 2>&1 &
# 3. звук и карточка
NODE_PATH=$(npm root -g) node tools/post5.cjs out/v5
# 4. видео 1920×1080 и лёгкая копия 1280×720
node tools/assemble5.cjs
node tools/assemble5.cjs --lite
```

«Анатомия» — так же:

```bash
NODE_PATH=$(npm root -g) node tools/export-cycles6.cjs out/cycles6
setsid nohup bash cycles/render6-all.sh > render6.log 2>&1 &     # 721 кадр, 16 сэмплов
NODE_PATH=$(npm root -g) node tools/post6.cjs out/v6
node tools/assemble5.cjs --frames out/cycles6/frames --post out/v6 --dur 30 --fade-in 0.4 --fade-out 29.35:0.65 --name orbita-pulse-one-v6
```

Или всё сразу, одним конвейером: `setsid nohup bash cycles/pipeline.sh &` (журнал — `out/pipeline.log`).
В плеере ролик выбирается переключателем или адресом `#anatomy` (`?film=anatomy` для инструментов).

Пробные кадры: `python3 cycles/render.py --data out/cycles --out out/cycles/test --res 1280x720 --spp 12 --hdr out/cycles/city.hdr --only 96,293,574`.
Кадры плеера three.js: `Q="&nomb&half" NODE_PATH=$(npm root -g) node tools/frames.cjs out/frames "4,12.2,22"`.

## Грабли v5 (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Кроссовок кувыркался и катился, как бревно | жёсткий контакт по одной точке → совместный контакт всех точек, потом мягкий: пена — пружина с демпфером в каждой точке |
| Симуляция «взрывалась» | сильное демпфирование при крупном шаге → шаг 1/24000 с |
| Кроссовок перекатывался на носок и падал набок | центр масс посередине → центр масс ближе к пятке, как у настоящего кроссовка |
| В Cycles белый кадр | мощности света перенесены как есть → калибровка в ваттах (витрина 150 Вт, фонарь 8000 Вт) |
| Мутная бежевая картинка | камера переведена в оси Blender дважды → у камеры свои оси совпадают, переводится только мир |
| Белёсый асфальт и серый фон | у узла Mix в Blender 4.5 четыре выхода «Result» → брать включённый выход нужного типа |
| Огромный диск фары | фара — шар 0,9 м у камеры → меньше и дальше, за кроссовком |
| Размытое макро | фокус цеплялся за струи дождя → автофокус лучом, дождь и брызги на время луча прячутся; f/11 |
| Контейнер падал (код 137) | рендер three.js и Cycles одновременно не помещались в память → по очереди |
| Капли в three.js — серые камешки | экранное преломление видит за каплей только асфальт → своя шаровая линза с панорамой города |
| Капли на белой пене — чёрные точки | линза рисовала тёмный город поверх ткани → капля на ткани только прибавляет отражение и блики |
| В «Анатомии» на белой пене чёрные крапины | при выгрузке экземпляры (капли дождя) запекались в меши и становились видимыми → спрятанные экземпляры не выгружаются |
| В Cycles чёрный трикотаж темнее, чем в плеере | в плеере светит ещё и студийная карта окружения → в Blender те же софтбоксы стоят панелями, невидимыми для камеры |
| Макро вдоль кроссовка — чёрные кадры | камера шла вдоль кромки подошвы, а полоса света — в стороне → камера скользит вдоль ткани, полоса ходит туда-обратно через кадр |
| Верхний прожектор выжигал пену | сила света 900 вместо 80 → пятно сверху ×0,09 |
| Фары машины едут сами по себе | машина была четырьмя светящимися шарами → кузов со стёклами и колёсами, фары и фонари в корпусе, свет фар — вперёд по ходу |
| Асфальт в three.js серый и в дымке | свет витрины на светлом скане и туман v4 → асфальт темнее, туман ×0,3 |

## Грабли v2–v4

| Симптом | Причина и лечение |
|---|---|
| Надпись на подошве зеркальная и не на той стороне | грани были вывернуты: камера видела внутреннюю сторону → поменять порядок вершин в треугольниках |
| Задник, накладки и «тросики» не видны | нормаль верха смотрела внутрь, накладки уходили под поверхность → нормаль считается как ∂s × ∂t |
| Кроссовок похож на слипон | боковины поднимались вертикально, а горловина была низкой → боковины наклонены внутрь, горловина и задник выше, сильнее рокер |
| Логотип напоминает чужой знак | изогнутый мазок с сужением → тонкая наклонная орбита с «планетой» |
| Жёсткая линия горизонта | пол заканчивался, а фон за ним светился → свечение фона гаснет к горизонту, дальний пол уходит в тот же тёмный цвет |
