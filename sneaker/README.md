# ORBITA Pulse One — рекламный 3D-ролик кроссовка кодом

32-секундный рекламный ролик бегового кроссовка на мокром ночном асфальте,
написанный кодом на [three.js](https://threejs.org): модель кроссовка, дождь,
вода, камера, надписи и музыка строятся формулами при загрузке страницы.
Скачаны только сканы, все свободные (CC0, [Poly Haven](https://polyhaven.com)):
панорама ночного Шанхая (огни города и отражения), асфальт и ткань канта.
ORBITA — вымышленная марка.

## Как посмотреть

```bash
cd sneaker
npx serve .
# открыть http://localhost:3000
```

Кнопка «Смотреть ролик со звуком» запускает рекламу. «Покрутить в 3D» включает
свободный осмотр: кроссовок можно вращать мышью или пальцем и менять расцветку
(Ember, Glacier, Volt). Пробел — пауза, ползунок — перемотка.

## Раскадровка

Музыка — 120 ударов в минуту, такт — 2 секунды; монтаж стоит на сильных долях.
12 планов: макро, наезды, отъезды, вид сверху и снизу, анфас; в каждом плане свет
движется отдельно от камеры.

## Реализм

- **Модель:** строчка вдоль задника, носка и шнуровки (сотни стежков-капсул),
  перфорация на носке, лёгкие волны и заломы трикотажа на сгибе, наконечники
  шнурков, плетёная фактура шнурков, шов между пеной и верхом.
- **Материалы:** трикотаж-меланж (у каждой петли свой тон), поры и
  шероховатость пены, анизотропный блик карбона, глянцевый задник.
- **Свет:** студийная карта окружения из светящихся панелей (отражения
  софтбоксов в глянце), тон-маппинг Neutral вместо киношного ACES, затенение в
  щелях и складках (GTAO), мягкие тени и размытое отражение в полу.

## Как сделать MP4

Нужны Node.js, ffmpeg и Playwright с Chromium. three.js для рендера берётся из
`node_modules` (`npm install`), шрифты Google один раз скачиваются в `tools/.fontcache`.

```bash
cd sneaker
npm install
# лист кадров
NODE_PATH=$(npm root -g) node tools/frames.cjs out/frames "1.5,5,7,9,11,13,15,17.5,21.7,24.2,25.5,30"
# видео 1920×1080, 24 к/с, звук выровнен до −14 LUFS
NODE_PATH=$(npm root -g) node tools/render.cjs out/orbita-pulse-one-v3.mp4 --fps 24
```

На машине без видеокарты (программный WebGL) обычный кадр рисуется 6–15
секунд, кадр со смазом — до полутора минут; весь ролик v4 — около четырёх часов
(запускайте рендер отдельным процессом, например через `setsid nohup`). С видеокартой
— в десятки раз быстрее. В адресе `?noao` отключает затенение в щелях, `?nomb` —
смаз движения.

## Грабли (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Надпись на подошве зеркальная и не на той стороне | грани были вывернуты: камера видела внутреннюю сторону → поменять порядок вершин в треугольниках |
| Задник, накладки и «тросики» не видны | нормаль верха смотрела внутрь, накладки уходили под поверхность → нормаль считается как ∂s × ∂t |
| Кроссовок похож на слипон | боковины поднимались вертикально, а горловина была низкой → боковины наклонены внутрь, горловина и задник выше, сильнее рокер |
| Логотип напоминает чужой знак | изогнутый мазок с сужением → тонкая наклонная орбита с «планетой» |
| Жёсткая линия горизонта | пол заканчивался, а фон за ним светился → свечение фона гаснет к горизонту, дальний пол уходит в тот же тёмный цвет |
| План бега выгорел в белое | 220 ярких штрихов летели между камерой и кроссовком → штрихи только позади и у самого пола, слабее |
| Подписи взрыв-схемы улетели к краю | надписи считались по матрице камеры из прошлого кадра → обновлять матрицу камеры до проекции |
| Шнурки светятся, как неон | белый цвет плюс «бархатный» отблеск (sheen) выше порога свечения → шнурки темнее, sheen слабее и серый, порог свечения 0,92 |
| Тонкая чёрная палка на фоне | погашенная световая полоса становилась чёрной, а не исчезала → прятать полосу, когда её яркость ноль |
| План пятки — тёмный цилиндр | камера стояла строго сзади, слишком близко → дуга три четверти сзади, дальше и выше, свой блик-«полоса» |
| Цифры и заголовки на кроссовке | в макро и при отрыве от пола кроссовок заполняет кадр → надписи в свободный угол, камера дальше |
| Кнопка «Смотреть» начинала с конца | плеер запускался с времени обложки (30,2 с) → с обложки всегда с нуля |
| Скриншот кадра падал по таймауту | кадр со смазом — это до 8 полных отрисовок, видеокарта (программная) не успевала за 30 с → ждать скриншот до 5 минут |
| Смаз «размазывал» кадр через склейку | окно затвора было по обе стороны от момента кадра → окно начинается в момент кадра |
| Точки у самой камеры давали сдвиг в тысячи пикселей | в макро точки-зонды оказывались вне кадра и улетали при проекции → учитывать только точки в кадре |
| Трикотаж посерел | «ворс» (sheen) был слишком сильным и светлым → слабее и темнее |
| Кадр в молочной дымке | огромные яркие диски боке и светлый фон заливали кадр, свечение копилось → диски мельче и тусклее, фон темнее, свечение ×0,7, мокрый асфальт темнее |
| Видна граница асфальта и неба | дальний асфальт тонул в тумане, а панорама над ним светлая → цилиндр дымки по горизонту |
| Брызги невидимы | капли с преломлением прозрачны на тёмном фоне → летящая вода — это блики: материал прибавляется к картинке и чуть светится |
| Капли на кроссовке похожи на снег | непрозрачные светлые полусферы → почти чёрные капли со сложением: остаётся только блик |
| Дождь на макро — как царапины | струи у самого объектива слишком крупные → на макро дождя почти нет, струи ближе 1 единицы гаснут |
| Струи дождя в затенении и глубине резкости | GTAO и Bokeh считали дождь твёрдым → «мягкие» объекты скрываются на время этих проходов |
| Ролик считался бы 7 часов | честное преломление в каплях — лишняя перерисовка сцены, тень фар всегда обновлялась → капли без преломления, тень фар только когда машина в кадре, на сильном смазе без GTAO, не больше 10 подкадров |
| Фоновая задача обрывала рендер | ожидание ограничено двумя часами → рендер запускается отдельным процессом |
