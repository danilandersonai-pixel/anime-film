# ORBITA Pulse One — рекламный 3D-ролик кроссовка кодом

22-секундный рекламный ролик бегового кроссовка, целиком написанный кодом на
[three.js](https://threejs.org): модель кроссовка, студийный свет, камера,
надписи и музыка. Ни одной скачанной модели, текстуры или звука — всё
строится формулами при загрузке страницы. ORBITA — вымышленная марка.

## Как посмотреть

```bash
cd sneaker
npx serve .
# открыть http://localhost:3000
```

Кнопка «Смотреть ролик со звуком» запускает рекламу. «Покрутить в 3D» включает
свободный осмотр: кроссовок можно вращать мышью или пальцем и менять расцветку
(Ember, Glacier, Volt). Пробел — пауза, ползунок — перемотка.

## Раскадровка

Музыка — 120 ударов в минуту, такт — 2 секунды; монтаж стоит на сильных долях.

| Время, с | План | Камера | Звук |
|---|---|---|---|
| 0–4 | Из темноты: полоса света пробегает вдоль бока, видны печать на пене и логотип-орбита | макро, медленный проезд вдоль кроссовка, малая глубина резкости | сердцебиение, свист вслед за светом, нарастание |
| 4–8 | Кроссовок парит и поворачивается, за ним огромная контурная надпись. «PULSE ONE» | облёт навстречу вращению | удар и вход бита |
| 8–12 | Взрыв-схема: верх, пена, карбоновая пластина, второй слой пены, подмётка расходятся; подписи к каждому слою; щелчок обратно | сверху в три четверти | «вжух» на разлёте, щелчки подписей, хлопок на сборке |
| 12–15 | Бег: кроссовок прилетает, бьёт пяткой, пена сжимается, по полу идёт волна, перекат на носок. «87 %» | у самого пола, с наклоном горизонта | гулкий удар на приземлении, свист на отталкивании |
| 15–17 | Расцветки Glacier и Volt меняются по ударам музыки | статичный ракурс в три четверти | аккорды-«стабы» |
| 17–22 | Пэкшот: логотип, «PULSE ONE», «Отрывайся от земли.», характеристики, «Скоро в продаже» | медленный наезд | финальный аккорд и колокольчик |

## Как устроено

| Файл | Что внутри |
|---|---|
| `js/shoe.js` | модель: колодка и рокер подошвы, два слоя пены и карбоновая пластина (сечения-суперэллипсы вдоль длины), подмётка, верх из «меридианов» от края подошвы к горловине, язык, шнурки крест-накрест с бантом, блочки, задник, накладки, «тросики» к блочкам, логотип, три расцветки |
| `js/textures.js` | процедурные текстуры: трикотаж, протектор-шеврон, саржевый карбон, рельеф пены с печатью модели, логотип-орбита |
| `js/stage.js` | студия: софтбокс и цветной контровой свет (RectAreaLight), чёрный глянцевый пол с отражением и мягкой контактной тенью, фон-циклорама со свечением, скоростные штрихи, постобработка (свечение, глубина резкости, виньетка, зерно, хроматическая аберрация) |
| `js/timeline.js` | режиссура: что происходит в каждый момент `t` |
| `js/overlay.js` | надписи и подписи-выноски (SVG в координатах кадра 1920×1080) |
| `js/audio.js` | музыка и звуковые акценты, синтезированные WebAudio |
| `js/main.js` | связка и плеер: воспроизведение по звуковым часам, перемотка, осмотр в 3D, подстройка разрешения под устройство |
| `tools/frames.cjs` | лист кадров для проверки |
| `tools/render.cjs` | рендер MP4 со звуком |
| `tools/lab.cjs`, `lab.html` | лист модели с восьми ракурсов |

## Как сделать MP4

Нужны Node.js, ffmpeg и Playwright с Chromium. three.js для рендера берётся из
`node_modules` (`npm install`), шрифты Google один раз скачиваются в `tools/.fontcache`.

```bash
cd sneaker
npm install
# лист кадров
NODE_PATH=$(npm root -g) node tools/frames.cjs out/frames "2,6,10.6,13.6,15.5,21"
# видео 1920×1080, 24 к/с, звук выровнен до −14 LUFS
NODE_PATH=$(npm root -g) node tools/render.cjs out/orbita-pulse-one.mp4 --fps 24
```

На машине без видеокарты (программный WebGL) кадр рисуется около 5 секунд,
весь ролик — около 45 минут. С видеокартой — в десятки раз быстрее.

## Грабли (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Надпись на подошве зеркальная и не на той стороне | грани были вывернуты: камера видела внутреннюю сторону → поменять порядок вершин в треугольниках |
| Задник, накладки и «тросики» не видны | нормаль верха смотрела внутрь, накладки уходили под поверхность → нормаль считается как ∂s × ∂t |
| Кроссовок похож на слипон | боковины поднимались вертикально, а горловина была низкой → боковины наклонены внутрь, горловина и задник выше, сильнее рокер |
| Логотип напоминает чужой знак | изогнутый мазок с сужением → тонкая наклонная орбита с «планетой» |
| Жёсткая линия горизонта | пол заканчивался, а фон за ним светился → свечение фона гаснет к горизонту, дальний пол уходит в тот же тёмный цвет |
| План бега выгорел в белое | 220 ярких штрихов летели между камерой и кроссовком → штрихи только позади и у самого пола, слабее |
| Подписи взрыв-схемы улетели к краю | надписи считались по матрице камеры из прошлого кадра → обновлять матрицу камеры до проекции |
